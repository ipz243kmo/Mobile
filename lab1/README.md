## 1. Опис проєкту

Мобільний застосунок створено на базі фреймворку **React Native** з використанням платформи **Expo**. Верстку та стилізацію інтерфейсу виконано за допомогою вбудованого **StyleSheet API** та макетної системи **Flexbox** у фірмовій кольоровій гамі Державного університету «Житомирська політехніка». Для відображення іконок використано бібліотеку `@expo/vector-icons` (`Ionicons`).

### Реалізовані екрани та компоненти:
1. **Спільна верхня шапка (`AppHeader`)**:
   - Відображає логотип університету, назву лабораторної роботи, прізвище, ініціали та групу студентки (*Куліш М.О., ІПЗ-24-3*), а також кнопку налаштувань.
2. **Нижня панель навігації (`Bottom Tabs`)**:
   - Забезпечує перемикання між трьома основними екранами застосунку (*«Головна»*, *«Галерея»*, *«Профіль»*) з динамічною зміною іконок та кольору активної вкладки.
3. **Екран «Головна» (`HomeScreen`)**:
   - Містить рядок пошуку (`TextInput`) для миттєвої фільтрації новин за заголовком або описом.
   - Відображає стрічку новин університету за допомогою компонента `FlatList` у вигляді карток із зображеннями, заголовками, датами та коротким описом.
4. **Екран «Галерея» (`GalleryScreen`)**:
   - Реалізує фотогалерею з інтерактивним перемикачем режиму відображення: **сітка у 2 колонки** (`numColumns={2}`) або **одноколонковий список** (`numColumns={1}`).
5. **Екран «Профіль» (`ProfileScreen`)**:
   - Дозволяє переглядати та редагувати персональні дані студентки (ПІБ, корпоративний Email `@student.ztu.edu.ua`, навчальну групу).
   - Містить кнопки збереження змін, скидання до початкових значень та перемикач (`Switch`) для керування сповіщеннями.

## 3. Інструкція із запуску

### Варіант А: Локальний запуск на комп'ютері (Node.js + Expo CLI)

1. **Клонування репозиторію:**
   ```bash
   git clone https://github.com/ipz243kmo/Mobile/lab1
   cd Mobile/lab1
   ```

2. **Встановлення залежностей:**
   ```bash
   npm install
   ```

3. **Запуск сервера розробки:**
   ```bash
   npx expo start
   ```
   Після запуску в терміналі з'явиться QR-код, який можна відсканувати за допомогою мобільного застосунку **Expo Go** (на Android) або стандартної камери (на iOS).

### Варіант Б: Запуск в онлайн-середовищі Expo Snack
1. Відкрийте проєкт у браузері на платформі [https://snack.expo.dev](https://snack.expo.dev).
2. Переглядайте інтерфейс у вбудованому веб-емуляторі або відскануйте QR-код через **Expo Go** на фізичному смартфоні.

## 5. Висновки: основні способи запуску мобільного додатка

Під час виконання лабораторної роботи №1 було вивчено структуру React Native проєкту на базі Expo, опановано базові компоненти (`View`, `Text`, `TextInput`, `Image`, `FlatList`, `ScrollView`, `TouchableOpacity`, `Switch`, `SafeAreaView`) та проведено тестування різних способів запуску мобільного застосунку:

1. **Стандартний запуск через локальну Wi-Fi мережу (`npx expo start` + Expo Go)**
   - **Призначення:** Швидке тестування та розробка застосунку безпосередньо на реальному фізичному смартфоні (Android або iOS).
   - **Особливості та відмінності:** Передача JavaScript-бандлу відбувається через локальну мережу, завдяки чому оновлення коду (**Fast Refresh**) спрацьовують миттєво. Не вимагає встановлення важких SDK або емуляторів на ПК, проте обов'язковою умовою є підключення комп'ютера і смартфона до однієї Wi-Fi мережі.

2. **Запуск в емуляторі Android (`npx expo start --android`)**
   - **Призначення:** Автоматичне відкриття та тестування застосунку у віртуальному пристрої Android Virtual Device (AVD) на комп'ютері.
   - **Особливості та відмінності:** Дозволяє перевіряти адаптивність верстки на різних розмірах екранів, роздільних здатностях та версіях ОС Android без наявності фізичного пристрою. На відміну від запуску на смартфоні, вимагає попереднього встановлення Android Studio та значних апаратних ресурсів (оперативної пам'яті та процесора).

3. **Запуск через тунельоване з'єднання (`npx expo start --tunnel`)**
   - **Призначення:** Тестування на фізичному пристрої у випадках, коли комп'ютер і смартфон знаходяться в різних мережах (наприклад, ПК підключений через кабельний інтернет, а смартфон — через мобільний зв'язок) або коли локальні порти заблоковані налаштуваннями маршрутизатора чи брандмауера.
   - **Особливості та відмінності:** Створює зовнішній захищений тунель (через сервіс Ngrok/Expo Tunnel), що робить сервер розробки доступним з будь-якої мережі. Відрізняється дещо повільнішим початковим завантаженням бандлу порівняно зі стандартним локальним режимом.

4. **Запуск із попереднім очищенням кешу (`npx expo start --clear`)**
   - **Призначення:** Усунення проблем зі складанням проєкту після встановлення нових бібліотек, зміни конфігураційних файлів або перейменування маршрутів.
   - **Особливості та відмінності:** Очищає локальний кеш збирача Metro Bundler перед стартом сервера, що гарантує коректне застосування всіх останніх змін у коді та залежностях.

5. **Онлайн-середовище розробки (`snack.expo.dev`)**
   - **Призначення:** Швидке прототипування, написання та запуск коду React Native безпосередньо у браузері без локального розгортання середовища розробки.
   - **Особливості та відмінності:** Дозволяє миттєво бачити результат у веб-прев'ю та запускати проєкт на смартфоні через Expo Go, проте має певні обмеження при використанні складних нативних модулів.
