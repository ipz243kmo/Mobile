# Лабораторна робота №4 — Опрацювання жестів користувача та реалізація інтерактивної взаємодії у React Native

**Дисципліна:** Розробка мобільних застосунків (React Native / Expo)  
**Тема:** Опрацювання жестів користувача та реалізація інтерактивної взаємодії у React Native.  
**Мета:** Засвоїти методи розпізнавання та опрацювання користувацьких жестів у середовищі React Native та реалізувати сценарії жестової взаємодії та їх пріоритезацію у мобільному додатку.

## 1. Опис проєкту та архітектура

Мобільний застосунок **«Clicker»** розроблено на базі **React Native**, **Expo Router** та бібліотеки **`react-native-gesture-handler`** (із використанням `react-native-safe-area-context` для коректного відображення інтерфейсу в межах безпечних зон екрана).

### Реалізовані екрани та жестові взаємодії:
1. **Головний екран («Клікер» — `app/index.jsx`)**:
   - Відображає поточний лічильник ігрових очок та інформаційний банер останньої розпізнаної дії.
   - Інтерактивний об'єкт реагує на **6 типів жестів** із налаштованою пріоритезацією (`waitFor`):
     - **`TapGestureHandler` (одиночний клік)**: коротке натискання нараховує **+1 очко** (очікує на завершення подвійного кліку та утримання для уникнення конфліктів).
     - **`TapGestureHandler` (`numberOfTaps={2}`)**: подвійне натискання нараховує **+2 очки** та активує перший етап комбінованого завдання.
     - **`LongPressGestureHandler` (`minDurationMs={3000}`)**: безперервне утримання об'єкта протягом 3 секунд нараховує **+5 бонусних очок** (або **+15 очок** при виконанні комбо після подвійного кліку).
     - **`PanGestureHandler`**: вільне перетягування інтерактивного об'єкта по ігровій області з плавною анімацією координат `translateX`, `translateY` та нарахуванням **+1 очка**.
     - **`FlingGestureHandler` (`Directions.RIGHT` та `Directions.LEFT`)**: швидкі свайпи вправо або вліво нараховують випадкову кількість бонусних очок (від **1 до 10**).
     - **`PinchGestureHandler`**: масштабування (збільшення/зменшення розміру об'єкта двома пальцями) змінює масштаб сфери та нараховує **+3 бонусних очки**.
2. **Сторінка із завданнями (`app/tasks.jsx`)**:
   - Відображає перелік із **8 завдань** (7 базових та 1 власне комбіноване) у реальному часі зі статусом (*«Виконано»* / *«В процесі»*) та індикатором прогресу:
     1. Зробити 10 кліків (`TapGestureHandler`);
     2. Зробити подвійний клік 5 разів (`Double Tap`);
     3. Утримувати об'єкт 3 секунди (`LongPressGestureHandler`);
     4. Перетягнути об'єкт (`PanGestureHandler`);
     5. Зробити свайп вправо та свайп вліво (`FlingGestureHandler`);
     6. Змінити розмір об'єкта (`PinchGestureHandler`);
     7. Отримати 100 очок;
     8. **Власне завдання («Комбо-майстер»)**: послідовно виконати подвійний клік (`Double Tap`), а потім утримання об'єкта протягом 3 секунд (`LongPressGestureHandler`).
3. **Сторінка налаштувань (`app/settings.jsx`)**:
   - Відображає загальні параметри застосунку, поточну статистику гравця, перемикачі підказок (`Switch`) та кнопку **«Скинути весь прогрес»** з підтвердженням через нативний діалог `Alert.alert()`.
4. **Навігація (`app/_layout.jsx`)**:
   - Реалізовано нижню навігаційну панель (`Tabs`) на основі файлової маршрутизації **Expo Router**, обгорнуту в `GestureHandlerRootView` та `SafeAreaProvider`.

## 2. Інструкція із запуску

1. **Клонуйте репозиторій та перейдіть до папки `lab4`:**
   ```bash
   git clone https://github.com/ipz243kmo/Mobile/lab4
   cd Mobile/lab4
   ```
2. **Встановіть залежності:**
   ```bash
   npm install
   ```
3. **Запустіть сервер розробки Expo:**
   - `npx expo start` — стандартний запуск сервера розробки (для підключення через **Expo Go**);
   - `npx expo start --android` — запуск в емуляторі Android (AVD);
   - `npx expo start --tunnel` — запуск через тунельоване з'єднання;
   - `npx expo start --clear` — запуск із попереднім очищенням кешу.

## 3. Висновки та відповіді на контрольні запитання

### Висновки
Під час виконання лабораторної роботи №4 було опановано методи розпізнавання та обробки користувацьких жестів на нативному рівні за допомогою бібліотеки `react-native-gesture-handler`. На практиці реалізовано взаємодію з одинарним та подвійним натисканням, тривалим утриманням, перетягуванням, швидкими свайпами та масштабуванням, а також налаштовано пріоритезацію конкуруючих жестів за допомогою рефів та властивості `waitFor`.

---

### Відповіді на контрольні запитання

#### 1. Які основні типи жестів надає бібліотека `react-native-gesture-handler` та для яких сценаріїв взаємодії вони призначені?
Бібліотека надає нативні розпізнавачі жестів, що працюють безпосередньо в UI-потоці:
- **`TapGestureHandler` (або `Gesture.Tap()`)** — розпізнає короткі натискання (одиночні, подвійні або з заданою кількістю тапів `numberOfTaps`). Використовується для кліків, лайків подвійним тапом, відкриття карток.
- **`LongPressGestureHandler` (`Gesture.LongPress()`)** — спрацьовує при утриманні пальця на елементі довше заданого часу (`minDurationMs`). Застосовується для виклику контекстних меню, запису голосових повідомлень або активації бонусних дій.
- **`PanGestureHandler` (`Gesture.Pan()`)** — відстежує безперервне переміщення пальця по екрану (`translationX`, `translationY`, `velocityX`, `velocityY`). Призначений для перетягування елементів (Drag-and-Drop), слайдерів та кастомних свайпів.
- **`FlingGestureHandler` (`Gesture.Fling()`)** — фіксує швидкий спрямований зсув (свайп) у вказаному напрямку (`Directions.LEFT`, `RIGHT`, `UP`, `DOWN`). Використовується для швидкого перегортання сторінок, карток або закриття повідомлень.
- **`PinchGestureHandler` (`Gesture.Pinch()`)** — розпізнає зведення та розведення двох пальців (`scale`). Застосовується для масштабування фотографій, карт та графічних об'єктів.
- **`RotationGestureHandler` (`Gesture.Rotation()`)** — відстежує обертання двома пальцями (`rotation`) для повороту зображень чи елементів інтерфейсу.

#### 2. У чому відмінність між обробкою переміщення об'єкта за допомогою `PanGestureHandler` та швидкого зсуву через `FlingGestureHandler`?
- **`PanGestureHandler`** є **безперервним жестом** (*continuous gesture*): він генерує потік подій (`onGestureEvent`) протягом усього часу руху пальця по екрану, надаючи точні поточні координати зміщення (`translationX`, `translationY`). Це дозволяє плавно «вести» об'єкт за пальцем користувача в реальному часі.
- **`FlingGestureHandler`** є **дискретним жестом** (*discrete gesture*): він не відстежує проміжні координати руху пальця, а лише фіксує факт того, що користувач виконав швидкий різкий рух у заданому напрямку (наприклад, `Directions.RIGHT`) із достатньою швидкістю, після чого одноразово переходить у стан `State.ACTIVE` / `State.END`.

#### 3. Навіщо у корені застосунку необхідно обгортати компоненти в `GestureHandlerRootView`?
Компонент **`GestureHandlerRootView`** ініціалізує нативний контекст розпізнавання жестів на рівні платформи (Android/iOS) та пов'язує нативну ієрархію View з системою обробки дотиків `react-native-gesture-handler`. Без цієї обгортки у корені застосунку (особливо на Android та всередині модальних вікон) нативні обробники жестів не отримуватимуть системні події дотику (`MotionEvent`), і жести просто не спрацьовуватимуть.

#### 4. Яким чином можна реалізувати одночасне або послідовне спрацьовування кількох жестів на одному елементі?
Для керування взаємодією та пріоритезацією кількох жестів на одному елементі використовуються такі механізми:
1. **У класичному API (`*GestureHandler`):**
   - **Послідовне очікування (`waitFor`)**: одному обробнику передається масив посилань (`useRef`) на інші обробники (наприклад, `<TapGestureHandler waitFor={[doubleTapRef, longPressRef]}>`). Одиночний клік спрацює лише тоді, коли система переконається, що подвійний клік чи тривале утримання не відбулися.
   - **Одночасне розпізнавання (`simultaneousHandlers`)**: дозволяє двом жестам (наприклад, `PinchGestureHandler` та `RotationGestureHandler`) працювати одночасно без блокування один одного.
2. **У сучасному API (`GestureDetector`):**
   - Використовуються композиційні методи **`Gesture.Simultaneous(gesture1, gesture2)`** (для одночасного виконання, наприклад масштабування + обертання), **`Gesture.Exclusive(highPriority, lowPriority)`** (для взаємовиключної пріоритезації, наприклад `doubleTap` перед `singleTap`) та **`Gesture.Race(gesture1, gesture2)`** (спрацьовує той жест, який першим розпізнається).
